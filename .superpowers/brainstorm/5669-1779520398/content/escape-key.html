Detailモードからの「戻る」操作をどうするか？

Escape も ← もPTYが使うので、Overviewへの戻り方が必要なのだ

A

Ctrl+\ （バックスラッシュ）

シンプルな1キー。ほぼすべてのCLIツールで未使用。
Ctrl+\ → Overview に戻る

◎

  • 1キーで直感的
  • 競合ほぼゼロ

△

  • 若干押しにくい
B

tmux風プレフィックスキー（推奨）

専用プレフィックス（例: Ctrl+G）を押してから操作する。
Ctrl+G ← または Ctrl+G Esc → Overview
Ctrl+G n → 新規セッション
Ctrl+G q → 終了

◎

  • 全操作を一元管理
  • 拡張しやすい
  • 競合ゼロ

△

  • 2キーストローク必要
C

固定ヘッダーバー常時表示

Detailモードでも最上部1行だけ常にオーバーレイ表示。
← Back claude-code #1 Ctrl+C quit
← キーを画面上のヘッダーでのみキャプチャ

◎

  • 操作が常に見えている
  • 直感的

△

  • PTYの表示が1行削られる
  • ヘッダーがツールと被ることも
