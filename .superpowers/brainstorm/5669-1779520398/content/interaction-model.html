どんな「一つのビュー」にしたい？

複数のAIエージェントを管理するとき、どのUXが合ってる？

┌── claude ────────┬── codex ─────────┐
│ > fix auth bug │ > add tests │
│ Reading files... │ Writing test... │
│ ✓ Done │ ⣾ Running... │
├── gemini ────────┼── copilot ───────┤
│ > explain code │ > refactor fn │
│ ⣾ Thinking... │ ✓ Done │
└──────────────────┴──────────────────┘

A: タイル型マルチペイン

全エージェントを同時に並べて表示。tmux的な感覚で、各エージェントの状況をリアルタイムで俯瞰できる

◎

  • 全体を一目で把握
  • 並列実行の視認性が高い

△

  • 画面が狭いと読みにくい
● claude ⣾ running fix auth bug
● codex ⣾ running add tests
● gemini ✓ done explain code
● copilot ✓ done refactor fn
─────────────────────────────────────────
[claude] Reading auth.ts...
[claude] Found issue in line 42
[codex] Writing test_auth.py...

B: ダッシュボード + ログストリーム

上部にエージェント一覧とステータス、下部に全エージェントの統合ログを流す。Claudeのagents viewに近い感じ

◎

  • ログの流れを追いやすい
  • 幅が狭くても機能する

△

  • 個別エージェントの詳細が見にくい
Agents: [claude*] [codex] [gemini] [copilot]
──────────────────────────────────────────
Agent: claude-code Status: ⣾ running
Task: fix auth bug
> Reading files...
> Found issue in auth.ts:42
> Applying fix...
✓ Completed

C: タブ切り替え型

上部にエージェントタブ、フォーカスしたエージェントの出力をフル画面で表示。バックグラウンドで他が動いているのは通知で分かる

◎

  • 一つのエージェントに集中できる
  • 出力が読みやすい

△

  • 並列実行の全体感が薄い
